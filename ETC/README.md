## 1. 디렉토리 개요

```
ETC/
├── 회의록/
│   ├── 회의록_Template.md      # 표준 주간/정기 회의록 템플릿
│   └── (날짜별 회의록 파일들)   # 팀 회의 결과 및 결정 사항 기록
├── Package_list.txt            # 전체 프로젝트 의존성 패키지 및 버전 스냅샷
└── README.md                   # ETC 디렉토리 안내
```

---

## 2. 회의록 관리 (`회의록/`)

* 팀원 간 원활한 커뮤니케이션과 의사결정 추적을 위해 회의 진행 시 [`회의록_Template.md`](./회의록/회의록_Template.md)를 복사하여 작성합니다.
* **파일명 규칙**: `YYYY-MM-DD_[회의주제].md` (예: `2026-10-16_Kickoff_회의록.md`)
* **주요 기록 항목**:
  1. 현재 진행 상황 (완료 과업 및 진척도)
  2. 이번 회의 내용 (핵심 안건별 결정 사항 및 주요 의견)
  3. 차주 진행 예정 과업
  4. 액션 아이템 (담당자, 마감 기한, 우선순위 명시)

---

## 3. 의존성 패키지 목록 (`Package_list.txt`)

* 프로젝트에서 사용된 모든 npm 패키지(프론트엔드 + 백엔드 + 전역 도구)의 버전 및 설치 사유를 기록한 아카이브 문서입니다.
* 패키지 충돌이나 신규 환경 세팅 시 레퍼런스로 활용할 수 있습니다.

---

## 4. 팀 협업 규칙 및 커밋 가이드

* **Git 커밋 컨벤션**:
  - `feat`: 새로운 기능 추가
  - `fix`: 버그 수정
  - `docs`: 문서 수정 (README, 회의록 등)
  - `style`: 코드 포맷팅, 세미콜론 누락 등 (코드 동작 변경 없음)
  - `refactor`: 코드 리팩토링
  - `test`: 테스트 코드 추가 및 수정
  - `chore`: 빌드 업무 수정, 패키지 매니저 수정 등
* **환경 변수 주의**:
  - 실제 `.env` 파일과 민감 정보(비밀번호, API 키)는 절대 Git에 커밋하지 않습니다.
